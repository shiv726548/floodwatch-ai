# Data Sources & Limitations

This prototype is intentionally built around simulated data for the demo environment. It should not be treated as live emergency information.

## Documented sources

- CWC FloodWatch — marked simulated or manually updated; no live public API assumed.
- IMD — marked simulated or manually updated; no live public API assumed.
- ISRO/NRSC — marked simulated or manually updated; no live public API assumed.
- State disaster authorities — manually updated only; not assumed to be API accessible.

## Operational limits

- This app is a decision-support prototype only.
- It never guarantees route safety and never tells a responder to cross floodwater.
- Human responders remain responsible for all triage and rescue decisions.
- Live sources are not assumed to exist for each dataset.
